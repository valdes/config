* Development Workflow

Emacs is the editing, navigation, diagnostics, compilation, and review surface.
Use a regular terminal or tmux session for builds, tests, logs, Git commands,
and agent CLIs.

** Work in Emacs

Project commands use Emacs's built-in =C-x p= prefix:

- =C-x p p=: switch project.
- =C-x p f=: find a project file.
- =C-x p b=: switch project buffer.
- =C-x p g=: search the project.
- =C-x p c=: compile from the project root.
- =C-x p k=: kill project buffers.

Use =C-c g d= to review tracked changes against =HEAD= with Difftastic.

Java buffers use =java-ts-mode= when the Home Manager managed tree-sitter
grammar is available. Eglot starts JDT LS directly; use standard Xref and Eglot
commands for navigation and refactoring, and =C-x p c= for tests and builds.

Git Gutter marks changed lines in file buffers. Use =C-c g p= and =C-c g n= to
visit the previous or next hunk, and =C-c g h= to preview the current hunk.
Magit refines changed words within every displayed diff hunk.

Use =F10= for buffers, =Shift+F10= for recent files, =C-.= for contextual
Embark actions, and =C-x g= for Magit.

** Share context with agents

Use =C-c x= to copy explicit project context:

- =C-c x f=: copy the current project-relative =file:line=.
- =C-c x r=: copy the active region with its file and line range.

Choose the agent, model, permissions, and working directory directly in the
agent CLI rather than through a repository wrapper.

** Maintain this configuration

After editing the repository, validate it with:

#+begin_src sh
  make check
#+end_src

Review the final diff before applying the configuration. Only update the live
home environment when intended:

#+begin_src sh
  make sync
  make switch
#+end_src

=make sync= installs the repo-managed Emacs, tmux, Niri, helper configuration,
and shared =manage-makefile= skill into the Codex and Claude skill directories.
