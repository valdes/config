* Config
Personal Linux workstation configuration.

The day-to-day coding loop is documented in [[file:DEVELOPMENT.org][DEVELOPMENT.org]].
That guide also covers using =templates/agent-task.md= from an Obsidian vault.

** Workflow

Bootstrap Home Manager with the repo flake:
#+begin_src sh :results output silent
  make prepare
#+end_src

Check prerequisites for the non-bootstrap targets:
#+begin_src sh :results output silent
  make doctor
#+end_src

Sync repo-managed files into place:
#+begin_src sh :results output silent
  make sync
#+end_src

Apply the Home Manager configuration:
#+begin_src sh :results output silent
  make switch
#+end_src

Do both in one step:
#+begin_src sh :results output silent
  make apply
#+end_src

** Noctalia

Noctalia v5 owns the shell surfaces around niri: bar, launcher, wallpaper,
notifications, clipboard history, lock screen, OSDs, and the control center.
Its declarative base configuration is in =home.nix=; GUI changes are stored
by Noctalia in =~/.local/state/noctalia/settings.toml= and override that base.

The host services remain distribution/systemd managed. The expected services are
NetworkManager, Bluetooth, UPower, power-profiles-daemon, PipeWire/WirePlumber,
GNOME Keyring Secret Service, polkit, and an XDG desktop portal. Check them
with:

#+begin_src sh :results output silent
  systemctl is-enabled NetworkManager bluetooth power-profiles-daemon
  systemctl --user status pipewire-pulse wireplumber
#+end_src

Install Niri, Noctalia, and host dependencies that are intentionally outside
Nix/Home Manager with the script matching the host distribution:

#+begin_src sh :results output silent
  ./bin/install-system-deps-arch
  # or, on Ubuntu 26.04:
  ./bin/install-system-deps-ubuntu26
#+end_src

Noctalia is started by niri after =make apply=; restart the niri session to
complete the cutover. To return temporarily to the previous shell, restore the
Waybar/swaybg startup lines and the original niri bindings, then rebuild.

Useful diagnostics:

#+begin_src sh :results output silent
  noctalia config validate
  noctalia msg --help
  journalctl --user -b | rg noctalia
#+end_src

** Emacs and agents

Emacs owns editing, navigation, diagnostics, compilation, and review. Agents run
in the project's tmux session:

#+begin_src sh :results output silent
  dev-session ~/work/project
  dev-session --launch ~/work/project
#+end_src

The session contains permanent =agent= and =shell= windows. Each isolated task
adds a window named after its task slug. New and resumed task windows start in a
read-only planning phase; implementation begins only after the operator reviews
the plan, unlocks write access, and explicitly approves it.

Emacs uses =C-c x= for explicit agent handoff:

- =C-c x a= opens the project session in Ghostty.
- =C-c x f= copies the current project-relative =file:line=.
- =C-c x r= copies the selected region with file and line context.
- =C-c x p= opens a personal task contract.
- =C-c x j= opens a ticketed job task contract.
- =C-c x s= archives and submits that contract to =dev-loop=.

Project navigation remains under =C-c p=. Saving or closing a task buffer never
submits it automatically. =Escape= deletes and cancels an unsubmitted draft;
submitted contracts remain archived under =~/tasks/=.

** niri-ctl

The =bin/niri-ctl= helper supports environment overrides for application and
project paths. Niri window rules own workspace and monitor placement.

- =NIRI_CTL_PROJECTS_DIR=
- =NIRI_CTL_TERMINAL=
- =NIRI_CTL_EDITOR=
- =NIRI_CTL_EMACSCLIENT=
- =NIRI_CTL_DEV_SESSION=
- =NIRI_CTL_BROWSER=

Example:
#+begin_src sh :results output silent
  NIRI_CTL_PROJECTS_DIR="$HOME/src" \
  NIRI_CTL_BROWSER=firefox \
  niri-ctl project
#+end_src

** Notes

- =make sync= installs the wallpaper to =~/.local/share/backgrounds/background.jpg=.
- =make prepare= runs Home Manager directly from this repo using a =path:= flake reference and uses =-b backup= to preserve pre-existing conflicting files on first activation.
- =make switch= runs =home-manager --impure switch=.
