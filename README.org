* Config
Personal Linux workstation configuration.

The day-to-day coding loop is documented in [[file:DEVELOPMENT.org][DEVELOPMENT.org]].
That guide also covers using =templates/agent-task.md= from an Obsidian vault.

** Workflow

Bootstrap Home Manager with the repo flake:
#+begin_src sh :results output silent
  make prepare
#+end_src

Check prerequisites for the non-bootstrap targets:
#+begin_src sh :results output silent
  make doctor
#+end_src

Sync repo-managed files into place:
#+begin_src sh :results output silent
  make sync
#+end_src

This also links the shared =manage-makefile= skill into the global Codex and
Claude skill directories.

Apply the Home Manager configuration:
#+begin_src sh :results output silent
  make switch
#+end_src

Do both in one step:
#+begin_src sh :results output silent
  make apply
#+end_src

** keyd

Home Manager installs the =keyd= CLI. The system daemon and its generated
=/etc/keyd/default.conf= are built from the structured mappings in =keyd.nix=
and kept in a root Nix profile.

Build and apply a new generation explicitly:
#+begin_src sh :results output silent
  make switch-keyd
#+end_src

The first switch preserves the existing configuration as
=/etc/keyd/default.conf.pre-nix=. Roll back one generation with:
#+begin_src sh :results output silent
  make rollback-keyd
#+end_src

Inspect the live service and generated configuration with:
#+begin_src sh :results output silent
  systemctl status keyd
  readlink -f /etc/keyd/default.conf
  keyd check /etc/keyd/default.conf
#+end_src

If a bad mapping captures the keyboard, press =Backspace+Escape+Enter= to stop
keyd. The distribution-provided keyd package can be removed after confirming
that the service runs from the Nix profile.

** Noctalia

Noctalia v5 owns the shell surfaces around niri: bar, launcher, wallpaper,
notifications, clipboard history, lock screen, OSDs, and the control center.
Its declarative base configuration is in =home.nix=; GUI changes are stored
by Noctalia in =~/.local/state/noctalia/settings.toml= and override that base.

The host services remain distribution/systemd managed. The expected services are
NetworkManager, Bluetooth, UPower, power-profiles-daemon, PipeWire/WirePlumber,
GNOME Keyring Secret Service, polkit, and an XDG desktop portal. Check them
with:

#+begin_src sh :results output silent
  systemctl is-enabled NetworkManager bluetooth power-profiles-daemon
  systemctl --user status pipewire-pulse wireplumber
#+end_src

Install Niri, Noctalia, and host dependencies that are intentionally outside
Nix/Home Manager with the script matching the host distribution:

#+begin_src sh :results output silent
  ./bin/install-system-deps-arch
  # or, on Ubuntu 26.04:
  ./bin/install-system-deps-ubuntu26
#+end_src

Noctalia is started by niri after =make apply=; restart the niri session to
complete the cutover. To return temporarily to the previous shell, restore the
Waybar/swaybg startup lines and the original niri bindings, then rebuild.

Useful diagnostics:

#+begin_src sh :results output silent
  noctalia config validate
  noctalia msg --help
  journalctl --user -b | rg noctalia
#+end_src

** Privacy baseline

Home Manager installs Firefox, KeePassXC, Restic, SOPS with age, Gitleaks, and
MAT2. Firefox is the default browser and installs uBlock Origin and
KeePassXC-Browser from Mozilla Add-ons. In KeePassXC, enable =Browser
Integration -> Firefox= once, then pair the extension with the unlocked
database. KeePassXC owns its mutable settings and databases; Home Manager owns
the package and native-messaging manifest.

Restic repositories are intentionally operator-selected. Initialize one on an
external or remote mount, run a backup, verify it, and test a restore before
depending on it:

#+begin_src sh :results output silent
  restic -r /mnt/backup/restic init
  restic -r /mnt/backup/restic backup "$HOME"
  restic -r /mnt/backup/restic check --read-data
  restic -r /mnt/backup/restic restore latest --target /tmp/restic-restore
#+end_src

Do not put the repository password in this repository. Restic prompts for it
when no password source is configured. Back up the password separately from the
repository.

Create an age identity outside Git before adding SOPS-encrypted secrets to a
project. Back up the identity separately, use the printed public recipient in
that project's =.sops.yaml=, and commit only SOPS-encrypted files:

#+begin_src sh :results output silent
  install -d -m 0700 "$HOME/.config/sops/age"
  age-keygen -o "$HOME/.config/sops/age/keys.txt"
  chmod 0600 "$HOME/.config/sops/age/keys.txt"
#+end_src

Scan committed history for secrets and make a metadata-cleaned copy before
sharing a supported document or image:

#+begin_src sh :results output silent
  make secrets-check
  mat2 document.pdf
#+end_src

The host dependency installers configure UFW with default-deny inbound traffic,
rate-limited SSH, and LocalSend on TCP/UDP port 53317. They preserve unrelated
rules rather than resetting the firewall. Docker-published ports can bypass UFW;
bind development services to loopback unless they are intentionally exposed.
Neither =make switch= nor =make sync= changes the live firewall.

VPN provider configuration, Tor routing, USBGuard, DNS proxies, and automated
Restic credentials remain explicit operator choices rather than workstation
defaults.

** Emacs and agents

Emacs owns editing, navigation, diagnostics, compilation, and review. Agents run
in the project's tmux session:

#+begin_src sh :results output silent
  dev-session ~/work/project
  dev-session --launch ~/work/project
#+end_src

The session contains permanent =agent= and =shell= windows. Each isolated task
adds a window named after its task slug. New and resumed task windows start in a
read-only planning phase; implementation begins only after the operator reviews
the plan, unlocks write access, and explicitly approves it.

Emacs uses =C-c x= for explicit agent handoff:

- =C-c x a= opens the project session in Ghostty.
- =C-c x f= copies the current project-relative =file:line=.
- =C-c x r= copies the selected region with file and line context.
- =C-c x p= opens a personal task contract.
- =C-c x j= opens a ticketed job task contract.
- =C-c x s= archives and submits that contract to =dev-loop=.

Project navigation remains under =C-c p=. Saving or closing a task buffer never
submits it automatically. =Escape= deletes and cancels an unsubmitted draft;
submitted contracts remain archived under =~/tasks/=.

** niri-ctl

The =bin/niri-ctl= helper supports environment overrides for application and
project paths. Niri window rules own workspace and monitor placement.

- =NIRI_CTL_PROJECTS_DIR=
- =NIRI_CTL_TERMINAL=
- =NIRI_CTL_EDITOR=
- =NIRI_CTL_EMACSCLIENT=
- =NIRI_CTL_DEV_SESSION=
- =NIRI_CTL_BROWSER=

Example:
#+begin_src sh :results output silent
  NIRI_CTL_PROJECTS_DIR="$HOME/src" \
  NIRI_CTL_BROWSER=firefox \
  niri-ctl project
#+end_src

** Notes

- =make sync= installs the wallpaper to =~/.local/share/backgrounds/background.jpg=.
- =make prepare= runs Home Manager directly from this repo using a =path:= flake reference and uses =-b backup= to preserve pre-existing conflicting files on first activation.
- =make switch= runs =home-manager --impure switch=.
